# tema-gida · zbtfya — Ürün Etiket Kartı (Gıda · TGK)

## Nedir

tema-gida sitesinin matrix modülü. `Ürün Etiket Kartı (Gıda · TGK)` şablonu (section kökü,
sınıf `modulex-ue`) render sırasında sitenin sayfa akışına eklenir. Şablon içeriği
`index.html`'deki `{{...}}` soketleriyle, veri/tema değerleri `index.json`'la
beslenir.

## Dosyalar

| Dosya | Rol |
|-------|-----|
| `back.js` | Modül davranışı (vanilla JS) (5 KB) |
| `index.html` | Modül şablonu (render hedefi) (6 KB) |
| `index.json` | Veri + tema token'ları (6 KB) |

## Temaya bağımlılık
Tema token'ları `index.json -> desing` üzerinden gelir (önceki tablo): **max**, **bgcolor**, **textcolor**, **mutedcolor**, **surface**.
